# Senriva Dependency Mapper

Dependency-aware HubSpot CMS intelligence demo for mapping relationships across pages, templates, modules, HubDB tables, and HubFS assets.

## Features

- Dependency graph modeling
- "Depends on" and "Used by" relationships
- Impact analysis
- Orphaned asset detection
- Broken dependency detection
- Production and staging awareness
- Source-to-target ID mapping
- Cross-account identity reconciliation
- Dependency-first reconstruction visualization
- Search and filtering

## Reconstruction Model

1. HubFS
2. Design Manager
3. HubDB
4. Pages
5. Verification

## Technology

- React
- TypeScript
- Vite
- Node.js
- Express
- REST API

## Safety

This public repository uses fictional demonstration data and contains no proprietary employer code, credentials, customer data, or production HubSpot content.

## Senriva

This project is part of an early Senriva portal-intelligence suite covering dependency analysis, asset management, content auditing, backup and recovery, migration readiness, and cross-account reconstruction.
